# IMRON BERE PERFORMANCE PANEL

Project Android yang meniru tampilan panel pada gambar referensi dengan tema hitam-merah.

Catatan:
- Panel ini adalah UI/performance dashboard saja.
- Tidak menginjeksi, memodifikasi, atau mengotomatisasi Free Fire.
- Toggle dan slider pada panel bersifat UI lokal.
- Build dapat dilakukan dengan AndroidIDE/Android Studio menggunakan Android Gradle Plugin 8.5.2.
- Jika memakai Termux, diperlukan Android SDK + Gradle yang sesuai.

Buka folder project ini, lalu build variant debug.


## GitHub Actions build
Upload this project to a GitHub repository, open **Actions**, choose **Build APK**, run it, then download the artifact **ImronBere-PerformancePanel-APK** from the completed run.
